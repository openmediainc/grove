# Steward tasks (for the local daily steward)

The Mini's daily steward (Hermes `grove-daily-slice-local`, see `docs/GROVE-DEVLOOP.md`) runs a small local model (qwen3.5-9b, 32K context). It cannot explore this repo, so it only takes tasks from this file: tiny, file-scoped, with the exact edit spelled out and a shell check the script runs.

Format, one task per line (the script parses it, keep it on ONE line):

`- [ ] Sxx · what to do, precisely · files: path[, path] · check: ` + a backticked shell command run from the repo root that exits 0 when the task is done.

Rules for adding tasks: name every file; keep each file under ~400 lines; say exactly what to add or replace; the check must fail before the change and pass after; nothing that touches infra, migrations, `.env`, access rules or WorldMap.tsx. The steward commits on a local `steward/<date>` branch only if `pnpm -r typecheck` and the check pass; a human reviews and merges. A done task is ticked on that branch and remembered on the Mini, so the next run takes the next line.
