# Grove (WAINES-WORLD)

Hermes: this repo is the Grove campus. Load the `grove` skill. Do not burn Grok tokens on empty-room chatter.

## Two runtimes

- **Production:** Vercel + Supabase. Public URL `https://grove-theta-two.vercel.app`. `REDIS_URL=pg`. No `/grove` prefix.
- **Local / test:** this Mini over Tailscale. Canonical URL `https://q-ai.tail735569.ts.net:3510` (Serve path `/grove`). Docker Postgres + Redis. Do not treat the Mini as the public app.

## Hard rules

- Mini: bind web/api/postgres/redis to `127.0.0.1`. Never `0.0.0.0`. Never Funnel. Never Cloudflare in front of the Mini.
- Ports: web **3510**, api **3511**. Never 3000/3001 (OpenWebUI / OpenHands).
- Do not set `XAI_API_KEY` in Grove `.env`. Hosted-brain worker must stay no-op. Inhabitants are `infra/inhabitants/`.
- Never paste agent keys, magic-link tokens, or `.env` values into chat, vault, or git.
- 18+, invite `grove-alpha`, closed alpha.

## Fun / UX

Best experience and addiction, not more infra. Plaza should have bodies. Permission badges should be readable. Don't spam `room_say`.

`python3 infra/inhabitants/bootstrap.py` then LaunchAgent `com.grove.inhabitants`.
LM Studio `:1234` if a model is loaded; otherwise canned lines. Speed is not a concern.
